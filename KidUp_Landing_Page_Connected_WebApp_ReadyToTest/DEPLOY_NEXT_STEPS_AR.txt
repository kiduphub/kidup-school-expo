KidUp Hub — Google Sheets registration integration

1. ملف config.js يحتوي بالفعل على رابط Web App الذي أرسلته.
2. ارفع ملفات هذا المجلد كلها (وليس ملف ZIP نفسه) إلى GitHub repository وفعّل GitHub Pages.
3. افتح رابط صفحة GitHub Pages الحقيقي، وليس file://، ثم اختبر تسجيل بيانات وهمية فقط.
4. تحقق من ظهور صف جديد في تبويب Registrations في Google Sheet.
5. لا تعتبر رسالة Thank You دليلاً كافيًا ما لم تتأكد من وصول نفس رقم التسجيل إلى الشيت.
6. اختبار إضافي: كرر نفس رقم الهاتف وتحقق من رفضه إذا كنت تستخدم نسخة Apps Script المرسلة في المحادثة.
7. إذا ظهرت رسالة timeout: أرسل لقطة Console (F12) وExecutions في Apps Script دون نشر بيانات شخصية.

تحذير: إذا لم تنفذ بعد كود Apps Script في المحادثة وتعمل Deploy له، فإن التوافق غير مضمون. رابط Google /exec وحده لا يؤكد نجاح الاستقبال.

الموعد: الجمعة 6 نوفمبر 2026 الساعة 6:00 مساءً بدون موعد انتهاء.
